# v1-prelude (archive)

2026-05-15 ~ 2026-05-24 발행분. 본 4 chapter (ep-01 ~ ep-04) 는 진혁의 *각성 전* 시기 (졸업식 마수 사건 → 비각성자 부대 입대 → 자대 첫 출동 + 최기준 사망) 를 다룬 prelude.

## archive 사유 (2026-05-25 결정)
사용자 평가 — 시놉시스 자체 약점:
1. 한국 헌터·각성물 표준 도입(부모 사망 + 동생 보호 + 군 입대) 반복.
2. 판타지 hook(각성)이 ep-05+로 늦음.
3. 주인공이 수동적(사건에 휘말리는 형태).
4. 톤 무거움(희생·내면 위주).

→ **새 v2** = *in media res 구조 재배치*. ep-01 cold open = 각성 사건 자체 (김성훈 사망 + 첫 *내게오라*). 진혁은 각성 후 비각성자 부대 퇴소 → **솔로 헌터** (길드 미가입, 능력 숨김). ep-04 = 첫 흡수(단계 1→2 전환점).
