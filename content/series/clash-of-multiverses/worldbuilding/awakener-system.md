# 차원 격돌 — 각성자 시스템 SSOT (awakener-system)

본 문서는 *각성 / 헌터 / 길드 / 헌터협회* 시스템 SSOT. ep-05 이후 작업의 모든 LLM 세션이 본 문서를 참고하여 정합을 유지한다. `writing-principles.md` 와 별개 — 본 문서는 **시스템 디테일 전용** (운영 원칙은 writing-principles).

---

## 1. 각성

### 1-1. 각성 = 단순 운
- 무작위로 떨어진다. **심사·평가 없음**.
- 특정 연령·신체·정신·노력으로 *얻는 것이 아님*.
- 인구 비율 = 적음 (정확 수치 TBD — 본문 노출 시점 결정).

### 1-2. 각성 표현 SSOT
- 올바름: *각성하지 못한 자* / *각성이 안 됐다* / *각성 안 된 사람* / *각성자* / *비각성자*
- 금지: *각성 심사에서 떨어졌다* / *한 번뿐인 각성 심사* / *각성 평가 통과 못 함*

### 1-3. 등급 측정 (각성 *후*)
- 각성 이후 **헌터협회** 의 등급 측정 절차를 거쳐 *랭킹* 이 매겨짐.
- 등급 = `S / A / B / C / D / E / F` 7 단계 (잠정 — 등급 체계 디테일 TBD).
- 우진혁 = 각성 시점 `C` 등급. F 등급도 비각성자 대비 *압도적* 으로 강함.
- 표현: *등급 측정* (등급 심사 X).
- **등급은 한 번 측정되면 변하지 않음** (`_series.md` 시놉시스 정합).

### 1-3a. 협회 측정 기술 한계 *(2026-05-25 신설 — 사용자 SSOT)*
- **측정 기계로는 등급까지만 잡힘**. 능력 계열·스킬·격 디테일 = 기계로 *못 잡음*.
- **능력 계열 분석** = 각성자 본인이 *스킬 시연* 해 줘야 협회 분석사가 분류 가능. **시연은 의무 아님** — 본인 거부 가능.
- **추측 분류** = 협회가 외부 단서 (현장 보고서 / 동료 목격담 / 마수 처치 양상 등) 로 *계열 추측*만 진행. 공식 분류 X.
- 본인 시연 없이 무한정 *공식 미분류* 상태로 활동 가능. C 등급 헌터 다수가 이 케이스 (대형 길드 일원이 아니면 분석 강제 압력 적음).
- **우진혁 사례 (ep-01)**: 본인이 각성 사실을 모른 채 보고서에 *시신이 일어났다* 한 줄을 적었기에, 헌터협회가 *네크로맨서 계열* 추측만 함. 진혁 본인도 능력 정체 모름 — 협회 프론트 밖에서 *옆 사람 어깨 부근 흐릿한 반짝* 첫 자각 (영혼 시각 초기 발현).
- **진혁의 시연 거부** = 본 시놉시스의 *공식 C 등급 vs 실측 격* 격차의 시작점. 시연을 평생 거부하며 *추정 네크로맨서* 분류 그대로 둠.

## 2. 헌터 (각성자)

### 2-1. 헌터 = 사냥꾼
- 각성자는 본 세계에서 **헌터** 라 불림. 군인 X. 군 산하 X.
- 마수 *사냥* 이 전담 임무. 비각성자 부대 (군) 와 *지휘 체계 분리*.

### 2-2. 헌터의 자유도
- *자율* 직업. 등록 (협회) 의무는 있지만 *어디서 누구와 활동할지* 는 본인 선택.
- 길드 가입 = 권장 (혜택 + 안전), 무소속 헌터도 존재 (자유 헌터, freelancer 같은 톤).

### 2-2-1. 헌터 = 직업 = 던전 부산물 수익 *(2026-05-19 신설, [[dungeon]] §4 정합)*
- 헌터는 **던전 클리어 보상 + 마수 시체 매각 + 던전 내 자원 채취·매각** 으로 수익.
- 등급별 수익 격차 큼 (S~A = 대형 던전 보스 = 대박 / D~F = 일반 마수 + 자원 채취 보조 = 생활급).
- 시놉시스 인용: *C 등급이면 먹고사는 데 지장이 없고, B 등급이면 대기업 직원만큼의 수입* ([`../_series.md`](../_series.md) §시놉시스).

### 2-3. 각성 후 비각성자 부대 잔류 예외 *(2026-05-19 신설, [[writing-principles]] §1-4 정합)*
- **표준** = 부대원이 임무 중 각성 → 헌터 길로 전환 → 부대 *퇴소*.
- **예외** = *본인 의지* 로 부대에 남는 케이스. 사유:
    1. **자대 동료에 대한 책임감** (특히 신참 멘토링 / 작전 중 인계 책임).
    2. **비각성자 부대 가치관 동의** — 마수 사냥 (헌터 영역) 보다 *민간인 피난·동선 차단* 의 가치를 더 두는 헌터.
    3. **각성 등급이 낮아 헌터 길에서의 효용보다 부대 영향력이 큰 케이스** (F~D 등급 잔류 케이스).
- 협회 등록은 의무 → 잔류 헌터도 *등록만 하고 헌터 활동 안 함* 케이스 가능.
- ep-05+ 챕터에서 본 예외 인물 등장 시 = lorekeeper 카드 *작가 분기 절* 격리.

## 3. 길드

### 3-1. 길드 = 각성자 헌터 단체
- *길드* 라는 단체로 헌터들이 활동.
- 길드별 능력·전문·등급·규모 분화.
- 본문 표현: *길드* / *길드 헌터* / *헌터 팀* / *(길드명) 헌터*.

### 3-2. 길드 등급
- 헌터협회가 길드 단위로도 등급을 매김 (잠정).
- 길드 등급 = 소속 헌터 평균 등급 + 출동 실적 + 규모 종합 (TBD).

### 3-3. 주요 길드 (TBD)
- *차원 격돌* 에 등장할 주요 길드명 / 인물 / 등급 = ep-05 이후 결정. (lorekeeper 와 협업.)

## 4. 헌터협회

### 4-1. 협회 = 각성자 정부
- 길드들을 관할하는 **최상위 조직**.
- 일반 (비각성자) 정부와 **별개**. 각성자 자치 정부 성격.
- 마수 출몰 신고 접수·헌터 팀 출동 지령·등급 측정 모두 협회 주관.

### 4-2. 협회 ↔ 군 (비각성자 부대) 협의 채널
- 마수 출현 시 = 협회 본부 ↔ 군 본부 협의 → 두 조직 동시 출동.
- 사냥 = 각성자 헌터 (협회). 민간인 피난·동선 차단·잔존 마수 견제 = 비각성자 부대 (군).
- ep-04 §5 본문 = 분대장 무전 *협회 통보로는 본진은 다섯 마리* / *협회에 추가 요청 넣었다* 정합 인용.

## 5. 마수 시스템 (개요)

### 5-1. 마수 = 차원 격돌의 적
- 본 세계의 *주적*. 다른 차원에서 유입.
- **던전 입구** 를 통해 출현. 던전 = 마수 본진 (차원 격돌 핵심 setting).

### 5-2. 마수 등급
- `S / A / B / C / D / E / F` (TBD — 헌터 등급과 별개 체계 or 동일 체계).
- ep-04 §5 = *C 등급 신고* (잠존 마수 2 마리, 본진 5 마리).

### 5-3. 마수 피부
- 비각성자 화기로는 *피부가 뚫리지 않음* (총탄이 튕겨 나가거나 흠집조차 못 냄). 각성자 헌터의 *능력* 으로만 효과적 타격.

### 5-3-1. 마수 시체 = 돈 *(2026-05-19 신설, [[dungeon]] §4-2 정합)*
- 처치된 마수의 시체 = 가죽 / 뼈 / 핵 / 체액 등 *재료 가치* (가공 후 산업·연구·소비재로 활용). 매입 시장 = 협회 주관 (또는 인가 업체).
- 헌터의 수익원 중 하나.

### 5-4. 던전
- 던전 입구 = 마수 출현 지점. 본진 = 던전 내부. 던전 내부에 *보스* + *지구에 없는 자원* 존재.
- **랜덤 발생** — 시간·장소 예측 불가. 발생 즉시 마수 지구 유입 → 사람 해침 → 시급 클리어 필요.
- **폐쇄 메커니즘** = *던전 내 보스 처치* (유일한 방법).
- ep-04 §5 본문 정합 인용: *길드 헌터들이 단지 안쪽 던전 입구에서 교전 중이다. 협회 통보로는 본진은 다섯 마리.*
- **상세 SSOT**: [`./dungeon.md`](./dungeon.md) *(2026-05-19 v2)* — 정의 / 발생 패턴 (랜덤 + 즉시 유입) / 폐쇄 메커니즘 (보스 처치) / 자원·경제 (지구에 없는 자원 + 시체 = 돈 + 헌터 수익원 4종) / 작전 분담 / 등급 / TBD.

### 5-5. 마수 출현 = 실전 = 사망 多 *(2026-05-19 신설, [[writing-principles]] §1-5 정합)*
- 마수 출현 작전 = 모의·훈련 아닌 *실전*. 한 작전에 사람 죽어 나옴.
- 비각성자 부대 (군) 측 인적 손실이 *통계상 최다 퇴소 사유* (사망). 작품 전체 톤이 *잔잔한 평화* 가 아닌 *상시 실전 위험* 임을 시스템 단에서 강제.
- 본 사실은 챕터 본문에서 *직접 표현* (전사 무전 / 의병 보고 / 동료 사망 장면) 로 박아야 함.
