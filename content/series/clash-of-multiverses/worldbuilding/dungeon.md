# 차원 격돌 — 던전 SSOT (dungeon)

본 문서는 *던전* 시스템 SSOT. ep-04 §5 본문 *던전 입구* 첫 등장 (2026-05-19) 이후 정합 유지 + 2026-05-19 사용자 명시로 핵심 메커니즘 (랜덤 발생 / 자원 / 마수 시체 = 돈 / 헌터 수익원 / 보스 처치 = 폐쇄) 확정.

[`awakener-system.md`](./awakener-system.md) §5-4 본 문서와 cross-link.

---

## 1. 정의

- **던전** = 차원 너머에서 마수가 *대량으로* 유입되는 *공간*. 본 세계 (지구) 의 *특정 좌표* 에 *입구* 가 열리고, 그 안쪽에 *마수 본진* + *보스* 가 존재.
- **던전 입구** = 본 세계 측 *균열·게이트*. 외부에서 시각으로 식별 가능. 비각성자도 *입구* 까지는 접근 가능 (안전 거리 한해).
- **던전 내부** = 입구 너머 *공간 자체*. 헌터만 진입 — 비각성자는 *입구 외 진입 불가 / 진입 시 즉사 위험* (TBD — 정확한 메커니즘 ep-05+ 결정).

---

## 2. 발생 패턴 *(2026-05-19 확정)*

### 2-1. 던전 = 랜덤 발생
- **시간 예측 불가** — 정해진 주기 X, 패턴 X. 갑자기 열림.
- **장소 예측 불가** — 도심·외곽·산·해안·실내·실외 무관. 어디든 열릴 수 있음.
- 각성자 협회 의 *조기 경보 시스템* 도 *발생 후 감지* 만 가능 — 사전 예측은 불가.

### 2-2. 던전 발생 = 마수 지구 유입 = 사람 해침
- 던전이 열리는 순간부터 *입구 너머 마수* 가 본 세계로 *흘러나오기* 시작.
- 처음 몇 마리 = *잔존 마수* → 입구 밖으로 흘러나와 *민간인 직접 공격*.
- 던전이 *오래 열려 있을수록* 더 많은 마수가 유입 → 피해 폭증.
- 따라서 **누구보다 빠르게 던전을 클리어해야 함** — 각성자 헌터의 최우선 임무.

### 2-3. 본진 vs 잔존 (ep-04 §5 정합 인용)
- **본진** = 던전 안쪽 다수 잔류 → 헌터 길드가 진입 작전.
- **잔존** = 입구 밖으로 흘러나온 마수 → 비각성자 부대 견제.
- ep-04 §5 본문 인용:
    - *길드 헌터들이 단지 안쪽 던전 입구에서 교전 중이다. 협회 통보로는 본진은 다섯 마리.*
    - *제기랄, 두 마리야. 잔존으로 흘러나왔다!*

## 3. 폐쇄 메커니즘 *(2026-05-19 확정)*

### 3-1. 던전 = 보스 처치 = 폐쇄
- **던전을 닫는 유일한 방법 = 던전 내부 보스 처치**.
- 보스 = 던전 본진의 *최강 개체*. 각성자 헌터 (특히 상위 등급) 의 *능력* 으로만 처치 가능.
- 보스가 살아 있는 한 던전 입구는 닫히지 않음 → 마수 계속 유입 → 피해 폭증.
- 일반 본진 마수를 모두 처치해도 *보스* 가 있으면 던전은 계속 열려 있음.

### 3-2. 클리어 시간 = 피해 규모 직결
- 던전 *발생 → 클리어* 시간이 길수록 잔존 마수 유입 ↑ = 민간인 피해 ↑.
- 협회 = 던전 등급에 따라 *권장 클리어 시간* 책정 + *헌터 팀 즉시 출동* 지령.
- 비각성자 부대 = 클리어 동안 *민간인 피난·동선 차단·잔존 마수 견제*. 사냥은 헌터 영역.

---

## 4. 자원 / 경제 시스템 *(2026-05-19 확정)*

### 4-1. 던전 내 자원 = 지구에 없는 자원
- 던전 내부에 *지구에 존재하지 않는 자원* (광물·식물·에너지·도구 등 — 구체 종류 TBD) 이 있음.
- 차원 너머의 *물리적·마법적 산물* — 본 세계의 산업·연구·소비재에 활용.
- **희소성** → 시장가 ↑ → 헌터의 *주요 수익원*.

### 4-2. 마수 시체 = 돈
- 처치된 마수의 시체도 *돈* 이 됨 — 가죽 / 뼈 / 핵 / 체액 등 *재료 가치* (가공 후 산업·연구·소비재로 활용).
- 마수 시체 처리·매입 시장 = 각성자 협회 주관 (또는 협회 인가 업체).
- 비각성자 부대의 잔존 마수 견제로 *처치한 시체* 도 시장 진입 가능 (다만 *사냥 = 헌터 책임* 정책상 비중은 작음).

### 4-3. 헌터의 수익원
- **헌터 = 직업 = 던전 부산물로 돈을 번다**.
- 수익 흐름:
    1. **던전 클리어 보상** (협회 지급 — 등급별 정해진 금액)
    2. **마수 시체 매각** (시장 가격 변동)
    3. **던전 내 자원 채취·매각** (희귀 자원일수록 가격 ↑)
    4. **길드 활동비·수수료** (소속 헌터에게 분배)
- 무소속 (자유 헌터) 도 협회 등록만 하면 수익 활동 가능 — 다만 길드 소속이 *안전 + 정보 공유* 측면에서 유리.

### 4-4. 등급별 수익 격차
- 상위 등급 헌터 (S~A) = 보스 처치 가능 → 대형 던전 진입 가능 → *대박 수익*.
- 하위 등급 헌터 (D~F) = 본진 일반 마수 처치 + 자원 채취 보조 → *생활급 수익*.
- 본 시리즈 시놉시스 인용: *C 등급이면 먹고사는 데 지장이 없고, B 등급이면 대기업 직원만큼의 수입이 보장된다* ([`../_series.md`](../_series.md) §시놉시스 — 작가 모드 마스킹).

## 5. 작전 분담 (정책 정합)

| 영역 | 담당 |
|---|---|
| **던전 내부 사냥** (본진 + 보스) | 각성자 헌터 (길드, 협회 출동 지령) |
| **던전 입구 외부 잔존 마수 견제** | 비각성자 정예 특수부대 (군) |
| **민간인 피난·동선 차단·경계** | 비각성자 정예 특수부대 (군) |
| **출몰 신고 접수 / 헌터 팀 출동 지령 / 등급 매김** | 각성자 협회 |
| **마수 시체·자원 매입 시장 주관** | 각성자 협회 (또는 인가 업체) |
| **군 ↔ 협회 협의** | 군 본부 ↔ 협회 본부 채널 (작전 동기화) |
