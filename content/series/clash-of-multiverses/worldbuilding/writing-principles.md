## 1. 비각성자 부대 = 자율 입대 정예 특수부대

본 세계의 비각성자 부대 = **일반 한국 군대 (강제 징병) 아님**. 자율 입대 정예 특수부대.

### 1-1. 입대 = 자율
- 강제 X. 본인 의지로 지원.
- "때 됐다 / 부모님이 일찍 가는 게 낫다 / 어쩔 수 없이" 같은 *일반 군대 톤* 절대 X.

### 1-2. 입대 동기 = 5 가지 중 하나
1. **돈** (가장 큰 이유). 위험 수당 두둑함. 보통 *지켜야 할 가족* 이 같이 따라옴.
2. **자부심 / 자긍심**. *마수 앞에 설 수 있는 자리는 여기뿐* 류.
3. **멋있어서**.
4. **할게 없어서** (마지못해 — 다만 *정신력 면접* 통과 못 하면 떨어짐).
5. **지켜야 할 무언가 / 마수에 대한 책임감·증오**. 가족이 마수에 잃었거나, 본인이 책임감 느끼는 경우.

### 1-3. 부대 위상 = 정예 특수부대
- **아무나 못 들어옴**. 사람도 많지 않음.
- **수료하기조차 힘듦**. 훈련소 = 일반 군대 톤 X.
- **신체 능력** 띄어남 필수 (우진혁 = 탈인간 수준).
- **정신력** 띄어남 필수. 신체만으로 안 됨.
- 보통 입대자 = *진짜 자부심* / *지켜야 할 무언가* / *마수 증오·책임* 중 하나는 있음.

### 1-4. "제대" 개념 X → 퇴소
- 일반 군대의 *제대 / 전역 / 의무 복무 기간 종료* 개념 **없음**.
- 퇴소 = (a) 더 이상 임무 수행 불가할 만큼 부상 (b) 자의 (스스로 떠남)
- 표현 = *퇴소* / *나감*. "제대할 때쯤", "전역" 절대 X.

### 1-5. 캐릭터별 입대 동기 SSOT
- **우진혁**: *돈* — 동생 (우선아) 학비 + 생활비. 목표 금액 모일 때까지 머묾. (부모만 잃고 동생 살아있음)
- **김성훈**: ***마수 증오 + 가족 전원 상실*** — 어릴 적 마수에게 가족 모두 잃음. 책임감·복수·분노. 다정한 톤은 본인 슬픔을 안으로 숨긴 결과.
- **최기준** (1조 일병, 선임): TBD (후속 결정. 보통 *지켜야 할 무언가* 또는 *자부심*).

### 1-6. 각성자 시스템 SSOT
- **각성 = 단순 운** (무작위). *심사* X. *평가* X.
- 입대 시 신체·정신 평가 = **비각성자 부대** 입소 평가일 뿐. *각성 심사 아님*.
- 표현 절대 금지: *한 번뿐인 각성 심사* / *각성 심사에서 떨어졌다* / *각성 평가 통과 못 함* 류.
- 올바른 표현: *각성하지 못한 자* / *각성이 안 됐다* / *각성 안 된 사람*.

### 1-7. 각성자 = 헌터 + 길드 + 각성자 협회 (군인 X)
- 각성자는 **헌터** (사냥꾼). 군인 X. 군 산하 X.
- "각성자 분대" / "각성자 부대" 표현 절대 X → **각성자 헌터** / **헌터 팀** / 단순 **헌터** / **각성자 (헌터)** 로.
- **길드** = 각성자 헌터들의 단체. 현 세상은 각성자가 *길드* 라는 단체로 이끔. 길드별 능력·전문·등급 분화.
- **각성자 협회** = 각성자 정부. 길드들을 관할하는 *최상위 조직*. 일반 (비각성자) 정부와는 별개의 *각성자 자치 정부* 로 해석. 마수 출몰 신고·헌터 팀 출동·등급 측정 등 모두 협회 주관.
- **비각성자 부대** (군, 정예 특수부대) ↔ **각성자 헌터** (길드 + 각성자 협회 = 별도 조직, 군 X). 둘이 *같은 현장* 출동하지만 *지휘 체계 분리*. 군 본부 ↔ 협회 간 협의 채널로 작전 동기화.
- 비각성자 부대 임무 = 민간인 피난·동선 차단·잔존 마수 견제. 사냥은 *각성자 헌터* (길드 / 협회) 책임.

## 2. 챕터 본문 톤 (액션·판타지·소설)

### 2-1. 절대 금지
- **시처럼 쓰기**. *한 박자 머물렀다 / 지나갔다 / 떨어졌다* 류 박자·정적 묘사 반복.
- **국어선생님 톤**. *손바닥은 어른의 무게였다* / *그 한 줄이 진혁의 십 년이었다* 류 시구·은유.
- **잔잔한 일과 묘사 위주**. 정복 점검 / 침구 정리 / 매트 손바닥 쓸기 같은 일상 디테일 — 한 두 줄 압축. § 절반 차지 X.
- **"~ 했다. 다. 했다."** 단조 종결어 반복 = 국어책 톤. 다양화 (~다 / ~었다 / ~는다 / ~지 / 의문 / 감탄 혼용).
- **단어 강조** `*...*` 남발 — 직접 인용 (안내문 / 무전 / 스피커) 만.
- **한 줄 = 한 단어** 시구 패턴.
- **"결"** 단어 절대 X.

### 2-2. 톤
- **액션·판타지·웹소설**. 화자가 *독자에게 이야기 전달* 하는 톤.
- **대화 중심**. 인물 간 *주고받는 대화* 가 사건 끌고 가야. § 절반 이상이 묘사·내면이면 위반.
- **사건 진행 + 인물 부딪힘 + (긴장감) 액션**. 잔잔한 일과·내면 회상 위주 = 톤 위반.
- **자연 한국어**. *유도 동기* (X — *유도 했던 동기*) / *첫 손이 간다* (X — *맡는다*) / *진하게 가다* (X — *세게 가다*) / *119 있다가 왔다* (X — *119 구조대에서 일하다 왔다*) 같은 어색 신조 X.

### 2-3. 군대 톤
- 같은 계급 동기끼리 자대 첫 만남 = **다나까 존대** (~ㅂ니다 / ~까 / ~ㅂ시오). 친한 친구 (훈련소 동기 등) = 반말 OK.
- 신참 → 분대장·선임 = 다나까 존대.
- 분대장 → 신참 = 반말 (직속 상관 톤).
- 다만 *일반 한국 군대 분위기* X. *정예 특수부대* 자부심 톤이 본문에서 느껴져야.

## 3. 캐릭터 카드 SSOT

### 3-1. 분리 작성 (CLAUDE.md 정책 #2)
- *공개 절* (`## 핵심 정체성` · `## 능력` · `## 인간관계` 등) — reader 빌드 노출.
- *작가 분기 절* (`## H-eries 분기 — {작품명} 변형`) — 작가 모드 마스킹 (정책 #9).

### 3-2. 스포일러 = 분기 절로만
- **사망 / 미래 사건 / 핵심 반전** = *공개 절* / role / summary / first_appearance / reader_snapshot 절대 노출 X.
- 모두 *H-eries 분기 절* 로만 격리.

### 3-3. 폴더 분류
- `1-protagonist` — 주인공 (진혁)
- `2-major-supporting` — 주연 (선아, 김성훈)
- `3-antagonist` — 빌런·라이벌
- `4-minor` — 단역·카메오·1~2 화 등장 인물 (최기준 = 여기)

### 3-4. origin = original
- 모든 등장 인물 / 세계관 / 고유명사 = 작가 본인 자작.
- 외부 작품 / 인물 / 진영 인용 0.
