# 차원 격돌 — 작가 원칙 SSOT (writing-principles)

본 문서는 작가 (홍도산) 가 *차원 격돌* (`clash-of-multiverses`) 의 본문·카드·세계관 작성 시 **모든 LLM 세션 / 모든 에이전트 / 모든 챕터 작업에 강제 적용** 되는 원칙. CLAUDE.md §핵심 원칙 #10 의 *작가 원칙 SSOT* 활성화 (2026-05-18).

위반 시 = 작품 톤 자체 무너짐. 이전 사이클에서 본 원칙 누락으로 사용자 분노 표명 다수.

## 1. 비각성자 부대 = 자율 입대 정예 특수부대

본 세계의 비각성자 부대 = **일반 한국 군대 (강제 징병) 아님**. 자율 입대 정예 특수부대.

### 1-1. 입대 = 자율
- 강제 X. 본인 의지로 지원.
- "때 됐다 / 부모님이 일찍 가는 게 낫다 / 어쩔 수 없이" 같은 *일반 군대 톤* 절대 X.

### 1-2. 입대 동기 = 5 가지 중 하나
1. **돈** (가장 큰 이유). 위험 수당 두둑함. 보통 *지켜야 할 가족* 이 같이 따라옴.
2. **자부심 / 자긍심**. *마수 앞에 설 수 있는 자리는 여기뿐* 류.
3. **멋있어서**.
4. **할게 없어서** (마지못해 — 다만 *정신력 면접* 통과 못 하면 떨어짐).
5. **지켜야 할 무언가 / 마수에 대한 책임감·증오**. 가족이 마수에 잃었거나, 본인이 책임감 느끼는 경우.

### 1-3. 부대 위상 = 정예 특수부대 (탈인간급)
- **아무나 못 들어옴**. 사람도 많지 않음.
- **수료하기조차 힘듦**. 훈련소 = 일반 군대 톤 X. 자원 입대해도 *대다수가 못 버티고 떨어짐*.
- **신체 능력** 띄어남 필수 (우진혁 = 탈인간 수준). 보통 정신으로는 못 함.
- **정신력** 띄어남 필수. 신체만으로 안 됨.
- *날고 긴다는 탈인간급* 정예가 모임. 그래서 **항상 인원 부족** — 신규 모집·수료자 어려워서 부대 정원 늘 미달.
- 보통 입대자 = *진짜 자부심* / *지켜야 할 무언가* / *마수 증오·책임* 중 하나는 있음. 동기 약하면 못 버팀.

### 1-4. 부대 = 비각성자 only (원칙) + 각성자 잔류 예외
- **구성원 = 비각성자만**. 본 부대는 *각성하지 못한 인간* 의 정예 특수부대.
- **임무 중 각성 시 = 보통 퇴소**. 각성자는 헌터 + 길드·협회 소속이라 별도 조직. 부대에서 빠져 헌터 길로 감.
- **예외 = 각성자 잔류**. 각성 후에도 *본인 의지* 로 부대에 남는 인원이 *드물게* 존재. 사유 = (a) 자대 동료에 대한 책임감 (b) 비각성자 신참 멘토링 (c) 본인 가치관 (마수 사냥보다 *민간인 피난·동선 차단* 가치 두는 헌터 출신).
- 예외 인물 = 작가 분기 절로만 표기 (스포 격리). 본문에서 직접 언급은 *각성 후에도 남기로 한 선임* 식으로.

### 1-5. 임무 위험 = 실전 多 → PTSD / 불구 / 죽음
- **마수 출몰 = 실전**. 모의·훈련 아님. 작전 한 번에 사람 죽어 나옴.
- 퇴소 사유 (실전 빈도순):
    1. **사망** (가장 많음). 마수에게 죽거나, 작전 실패로 잔존 마수에 휩쓸림. *죽어서 퇴소* 가 통계상 최다.
    2. **불구·중상**. 마수의 공격·산성·열기에 사지 절단·내장 손상. *더 이상 임무 수행 불가* 판정 = 강제 퇴소 (의병).
    3. **PTSD / 정신 붕괴**. 동료 사망·민간인 학살 목격·반복 작전으로 정신 무너짐. 입소 정신력 필터 통과한 정예라도 *지속 노출* 에는 무너짐. 자살 사례도 있음.
    4. **자의 (탈진)**. *더는 못 하겠다* — 본인이 한계 인정하고 떠남. 수치는 아님 (부대 내 *남아 있는 자체* 가 이미 비범).
    5. **자의 (목표 달성)**. 진혁처럼 *목표 금액 / 동생 자립* 같은 개인 목표 달성하면 떠남.
- 일반 군대의 *제대 / 전역 / 의무 복무 기간 종료* 개념 **없음**.
- 표현 = *퇴소* / *나감* / *전사* / *의병* / *순직*. "제대할 때쯤", "전역" 절대 X.

### 1-6. 캐릭터별 입대 동기 SSOT
- **우진혁**: *돈* — 동생 (우선아) 학비 + 생활비. 목표 금액 모일 때까지 머묾. (부모만 잃고 동생 살아있음)
- **김성훈**: ***마수 증오 + 가족 전원 상실*** — 어릴 적 마수에게 가족 모두 잃음. 책임감·복수·분노. 다정한 톤은 본인 슬픔을 안으로 숨긴 결과.
- **최기준** (1조 일병, 선임): TBD (후속 결정. 보통 *지켜야 할 무언가* 또는 *자부심*).

### 1-7. 각성자 시스템 SSOT
- **각성 = 단순 운** (무작위). *심사* X. *평가* X.
- 입대 시 신체·정신 평가 = **비각성자 부대** 입소 평가일 뿐. *각성 심사 아님*.
- 표현 절대 금지: *한 번뿐인 각성 심사* / *각성 심사에서 떨어졌다* / *각성 평가 통과 못 함* 류.
- 올바른 표현: *각성하지 못한 자* / *각성이 안 됐다* / *각성 안 된 사람*.

### 1-8. 각성자 = 헌터 + 길드 + 각성자 협회 (군인 X)
> 시스템 상세 = [`awakener-system.md`](./awakener-system.md) 참조 (등급 측정 / 마수 등급 / 던전 / 협회 ↔ 군 협의 채널 등).

- 각성자는 **헌터** (사냥꾼). 군인 X. 군 산하 X.
- "각성자 분대" / "각성자 부대" 표현 절대 X → **각성자 헌터** / **헌터 팀** / 단순 **헌터** / **각성자 (헌터)** 로.
- **길드** = 각성자 헌터들의 단체. 현 세상은 각성자가 *길드* 라는 단체로 이끔. 길드별 능력·전문·등급 분화.
- **각성자 협회** = 각성자 정부. 길드들을 관할하는 *최상위 조직*. 일반 (비각성자) 정부와는 별개의 *각성자 자치 정부* 로 해석. 마수 출몰 신고·헌터 팀 출동·등급 측정 등 모두 협회 주관.
- **비각성자 부대** (군, 정예 특수부대) ↔ **각성자 헌터** (길드 + 각성자 협회 = 별도 조직, 군 X). 둘이 *같은 현장* 출동하지만 *지휘 체계 분리*. 군 본부 ↔ 협회 간 협의 채널로 작전 동기화.
- 비각성자 부대 임무 = 민간인 피난·동선 차단·잔존 마수 견제. 사냥은 *각성자 헌터* (길드 / 협회) 책임.

## 2. 챕터 본문 톤 (액션·판타지·소설)

### 2-1. 절대 금지
- **시처럼 쓰기**. *한 박자 머물렀다 / 지나갔다 / 떨어졌다* 류 박자·정적 묘사 반복.
- **국어선생님 톤**. *손바닥은 어른의 무게였다* / *그 한 줄이 진혁의 십 년이었다* 류 시구·은유.
- **잔잔한 일과 묘사 위주**. 정복 점검 / 침구 정리 / 매트 손바닥 쓸기 같은 일상 디테일 — 한 두 줄 압축. § 절반 차지 X.
- **"~ 했다. 다. 했다."** 단조 종결어 반복 = 국어책 톤. **단조 평서 과거 "~었다." 3행 연속 절대 X** *(2026-05-24 강제)*. 매 §마다 아래 §2-1.5 도구상자에서 ≥3 패턴 혼용. 자체 검증 = `grep -cE '다\.$'` + `awk '/다\.$/{c++} else{c=0} c>=3{print NR}'` 0건.
- **단어 강조** `*...*` 남발 — 직접 인용 (안내문 / 무전 / 스피커) 만. **내면 사고 / 사고 흐름 X** *(2026-05-19 신규 명시)*: *이걸 계속해도 되나* / *움직여야 한다* 등 내면 사고는 일반 산문 흐름 (큰따옴표 없이) 으로 통합. *...* 둘러쌈 X.
- **한 줄 = 한 단어** 시구 패턴. *그 사람.* / *— 십 년 전.* 같은 *한 문장 = 한 명사* 단독 끊김도 위반 (chapter break 시간 표기 = 예외).
- **"결"** 단어 절대 X.

### 2-1.5. 종결어 다양화 도구상자 *(2026-05-24 신규 — 현대 한국 웹소설 톤 강제)*

단조 "~었다." 평서 과거 반복 회피용. 매 §마다 아래 도구 중 ≥3 종 혼용. **A+C 하이브리드 (자연 산문 + 감각·부사) = 본 작품 기본 패턴.**

#### A. 연결어미 + 호흡 묶기 (기본)
짧은 동작 2~3 개를 한 문장에 묶음. 한국어 자연 산문의 기본.
- 연결어미: `-자`, `-며`, `-면서`, `-는 사이`, `-는 순간`, `-자마자`, `-는데`, `-더니`
- 예: ~~"신호가 바뀌었다. 어머니가 진혁의 손을 꽉 쥐었다."~~ → "신호가 바뀌자 어머니가 진혁의 손을 한 번 더 꽉 쥐었다."

#### B. 현재형 인서트 (액션·긴장 순간만)
액션·전환·위협의 한 순간을 현재형 `-ㄴ다/는다` 로. 평상시 회상·일상은 과거형 유지.
- 예: "마수의 팔이 올라온다. 진혁이 한 발 물러난다."
- 주의: 현재형 남발 시 일관성 무너짐. § 안에 1~2 회 인서트가 적정.

#### C. 감각·부사·명사 종결 (영상감)
의성어·의태어·짧은 명사 단독·시간 부사로 장면 제시.
- 의성어/의태어: 쾅. / 휙. / 툭. / 쩌적.
- 부사 단독: 잠시. / 한참. / 마침내.
- 명사 단독: 한 발. / 두 발째. / 침묵.
- 예: "한 발. 두 발째를 디디기 전이었다. 등 뒤에서 — 쾅."

#### D. 종결 어미 변주 (마무리 강세)
같은 과거 시제 안에서도 어미 변주:
- `-었다` → `-았던 것이다` / `-아 버렸다` / `-고 말았다` / `-아 있었다` / `-아 왔다`
- 평서 → 의문·감탄·종결사: `-지` / `-야` / `-군` / `-잖아` / `-네` (단, narration 한정 — 인물 시점 가까울 때만)

#### E. 문장 길이 변주
짧-짧-긴 / 긴-짧 패턴. 같은 길이 문장 3행 연속 X.

#### F. 감각 한 줄 끼우기
동작 사이에 청각·시각·촉각 한 줄. 동작-감각-동작 리듬.
- 예: "진혁이 칼을 뽑았다. 손잡이의 매듭이 손가락에 박혔다. 발이 매트 가장자리를 짚었다."

#### G. 호명·짧은 대사 인서트
narration 단조 시 짧은 대사 한 줄 끼움 (호명 / 감탄 / 짧은 답).
- 예: 묘사 3행 → "…뭐야." → 묘사 1행.

#### H. 대사 내부 종결어 변주 *(2026-05-24 신규 — 사용자 지적)*
**대사도 단조 종결 적용** — 한 대사 안에서 *"~어. ~어. ~어."* / *"~다. ~다."* 3연속 절대 X. "뚝뚝 끊기는" 톤.
- ~~"오늘 강당에서 의자 한 번 휘둘렀어. 부서졌어. 마수는 안 움직였어."~~ (3연속 ~어. 단조)
- 개선: "오늘 강당에서 의자 한 자루 휘둘렀어. 그게 부서지는데 마수는 미동도 없더라."
  - 연결어미(-는데/-자/-고/-자마자) 로 두 사건 묶음
  - 마지막에 회상·인상 어미(-더라/-던데/-잖아/-거든) 변주
- 같은 인물 톤 유지 — 진혁(말 적은 자)은 짧지만 종결어 다양화 필수. 짧다 = 단조 허용 X.
- 명령·매뉴얼 톤(군 콜사인 등)도 4단 이상 동일 종결 시 한두 개는 변주 (예: "첫째, ~ 있어. 둘째, ~ 답해라. 셋째, ~ 끌어. 혼자 빠지지 말고.").
- **액션·판타지·웹소설**. 화자가 *독자에게 이야기 전달* 하는 톤. 국어책·교과서 X. 사건·인물·긴장이 *독자 머릿속에 그림으로 떠야*.
- **대화 중심**. 인물 간 *주고받는 대화* 가 사건 끌고 가야. § 절반 이상이 묘사·내면이면 위반.
- **사건 진행 + 인물 부딪힘 + (긴장감) 액션**. 잔잔한 일과·내면 회상 위주 = 톤 위반.
- **한국어 문법 정합**. 앞뒤가 안 맞는 한국어 X. 주어·서술어 호응 X (예: *유도 동기* — *유도* 가 명사인데 동사처럼 쓰임). 조사 오용 X. 시제 일관 X 인 한 문장 X. 한 번 읽고 *어색하다* 느낌 들면 정정.
- **자연 한국어**. 어색 신조 / 직역 / 잘못된 합성어 절대 X. 사용자 분노 표명 사례:
    - *유도 동기* → *유도 했던 동기*
    - *첫 손이 간다* → *맡는다*
    - *진하게 가다* → *세게 가다*
    - *119 있다가 왔다* → *119 구조대에서 일하다 왔다*
    - *한 박자 머물렀다* → *잠시 멈췄다* / 또는 그냥 빼기
    - **주어 mismatch** *(2026-05-19 신규)*: *너 같은 신체가 거기 가야지* → *너 같은 애가 거기 가야지* (*신체* 가 주어 = 호응 X. *애·놈·사람* 등 인격 명사 주어로). *어머니의 어깨가 진혁을 밀고* → *어머니가 진혁의 어깨를 밀고* (소유격 + 신체 부위가 행위 주어 = 어색).
    - **목적어 누락** *(2026-05-19 신규)*: *체육 선생이 육상부에 데려갔다* → *체육 선생이 진혁을 육상부에 데려갔다* (타동사 *데려가다* 의 목적어 명시).
    - **띄어쓰기**: *두마리* → *두 마리* (수관형사 + 의존명사) / *죽일겁니다* → *죽일 겁니다* (관형형 + 의존명사 *것*).
    - **잘못된 단위 명사 결합** *(2026-05-19 신규)*: *N 겹* (옷·천·종이 등 얇은 *층* 단위) 을 *피부 / 가죽 / 외피* 같은 단단한 표면에 사용 X. 한국어에는 *단위 명사 + 대상 명사* 가 자연 결합해야 함 — *N 개 / N 명 / N 마리 / N 그루 / N 자루* 등 대상별 단위가 다름.
    - **부적합 어휘 선택** *(2026-05-19 신규)*: *갑각* (甲殼 = 게·새우 등 절지동물의 단단한 외피) 을 짐승형 마수에 사용 X → *피부* (살아있는 시점 본문) / *가죽* (시체 가공 재료) 으로 분리. 사용자 분노 표명: *갑각 한 겹도 못 뚫는다* → *피부에 흠집도 못 낸다* / *피부조차 뚫리지 않는다*. 어휘는 *대상의 성질 + 맥락* 에 맞아야 함 (절지동물 X → 짐승형 동물 O).

### 2-3. 군대 톤
- 같은 계급 동기끼리 자대 첫 만남 = **다나까 존대** (~ㅂ니다 / ~까 / ~ㅂ시오). 친한 친구 (훈련소 동기 등) = 반말 OK.
- 신참 → 분대장·선임 = 다나까 존대.
- 분대장 → 신참 = 반말 (직속 상관 톤).
- 다만 *일반 한국 군대 분위기* X. *정예 특수부대* 자부심 톤이 본문에서 느껴져야.

## 3. 캐릭터 카드 SSOT

### 3-1. 분리 작성 (CLAUDE.md 정책 #2)

### 3-2. 스포일러 = 분기 절로만
- **사망 / 미래 사건 / 핵심 반전** = *공개 절* / role / summary / first_appearance / reader_snapshot 절대 노출 X.
- 모두 *H-eries 분기 절* 로만 격리.

### 3-3. 폴더 분류
- `1-protagonist` — 주인공 (진혁)
- `2-major-supporting` — 주연 (선아, 김성훈)

### 3-4. origin = original
- 모든 등장 인물 / 세계관 / 고유명사 = 작가 본인 자작.
- 외부 작품 / 인물 / 진영 인용 0.
